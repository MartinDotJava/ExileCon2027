
# ExileCon 2027

A fictional action RPG convention website created as a school project.

## Live Website

https://martindotjava.github.io/ExileCon2027/

## Features

- Responsive design for mobile, tablet, and desktop
- Conference schedule with five presentations
- Speaker gallery with five fictional speakers
- Three ticket tiers
- Venue information and static map
- Light and dark theme support
- CSS animations and hover effects
- Keyboard navigation and visible focus indicators

## Technologies

- HTML5
- Sass (SCSS)
- CSS Grid
- Flexbox
- CSS Media Queries

## Development

Install dependencies:

```bash
npm install
```

Start Sass in watch mode:

```bash
npm run dev
```

Build the CSS:

```bash
npm run build
```

## Disclaimer

This is a fictional educational project. ExileCon 2027 is not a real event. Speaker portraits are AI-generated.
